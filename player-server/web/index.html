        Scan settings

        Loading effective settings…

        Configure on the server, then restart: SCAN_WATCH_SECONDS=30 enables source polling (0 disables; 10–86400 seconds). SCAN_INTERVAL_MINUTES=60 schedules scans (0 disables; 1–10080 minutes). Both default off. Roots are managed in Libraries. Polling checks file names, size and modification time; a same-size edit with unchanged time needs a manual rescan. Automatic scans retain absent records; manual rescans use the existing deletion policy. Generated caches are ignored.
